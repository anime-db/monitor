# Устройство проекта `anime-db/monitor`

Как проект устроен внутри и какое место занимает в экосистеме [anime-db](https://github.com/anime-db). Техническая глубина — в [TECHNICAL.md](TECHNICAL.md).

## Место в экосистеме anime-db

Anime DB — это веб-приложение на **Symfony/PHP** для ведения личной коллекции аниме. Оно состоит из нескольких репозиториев-компонентов (`anime-db`, `app-bundle`, `catalog-bundle`, `anime-db-docs`). Конечному пользователю на Windows неудобно вручную запускать PHP-сервер и консольные команды Symfony — для этого и существует **`monitor`**.

```
Пользователь Windows
        │ кликает ярлык
        ▼
  anime_monitor.exe  ◄── ЭТОТ репозиторий (C++/Qt, трей)
        │ запускает два процесса PHP
        ├──────────────► php -S 0.0.0.0:56780 -t web app/router.php   (веб-сервер)
        └──────────────► php -f app/console animedb:task-scheduler    (планировщик)
        │ открывает браузер
        ▼
  http://localhost:56780/  ◄── веб-приложение Anime DB (Symfony)
```

`monitor` **не содержит** бизнес-логики аниме-каталога. Он знает только про:
- путь к интерпретатору PHP;
- адрес/порт, на которых поднять сервер;
- расположение `app/` и `web/` в дистрибутиве Anime DB;
- иконку в трее и меню управления.

## Структура репозитория

| Файл / группа              | Роль                                                                |
|----------------------------|---------------------------------------------------------------------|
| `main.cpp`                 | Точка входа: single-instance, загрузка перевода, создание трея      |
| `TrayIcon.{h,cpp}`         | Ядро: иконка трея, меню, управление двумя процессами PHP            |
| `MSettings.{h,cpp}`        | Синглтон-обёртка над `QSettings` (файл `config.ini`)                |
| `anime_monitor.pro`        | Проект qmake — **единственный источник** списка файлов сборки       |
| `anime_monitor.pro.user`   | Состояние Qt Creator (не должно быть в VCS, см. [BUGS.md](BUGS.md)) |
| `icons.qrc`                | Ресурсы Qt: `tray.png`, `favicon.ico` (встраиваются в exe)          |
| `myapp.rc` + `favicon.ico` | Иконка самого exe (Windows resource через `RC_FILE`)                |
| `ru.ts` / `ru.qm`          | Перевод на русский (исходник Qt Linguist / скомпилированный бинарь) |
| `tray.png`                 | Иконка в трее                                                       |
| `LICENSE`                  | GPLv3                                                               |
| `README.md`                | Краткое описание                                                    |

## Поток выполнения (жизненный цикл)

1. **Старт.** `main()` создаёт `QApplication`, проверяет единственность экземпляра через `QSharedMemory("anime_monitor")`. Если копия уже запущена — выход с кодом `1`.
2. **Локализация.** Если страна локали — `RussianFederation`, грузится `ru.qm`. (Ограничение, см. [BUGS.md#b4](BUGS.md).)
3. **Трей.** Создаётся `TrayIcon`: проверяется путь приложения (только ASCII), при смене папки чистится кэш Symfony, строятся меню.
4. **Автозапуск.** Через 1 секунду срабатывает таймер → `startSlot()` → запускаются оба процесса PHP и открывается браузер.
5. **Управление.** Пользователь через меню трея может Start / Stop / Restart, посмотреть About (открывает сайт), выйти.
6. **Выход.** Освобождается сегмент разделяемой памяти. Дочерние процессы PHP при этом **не останавливаются явно** в `quit` (нюанс жизненного цикла — см. [TECHNICAL.md](TECHNICAL.md)).

## Меню

| Триггер                        | Действие                                    |
|--------------------------------|---------------------------------------------|
| Правый клик (контекстное меню) | About, Exit                                 |
| Левый клик (`reason == 3`)     | Ручное меню: Start, Stop, Restart           |
| About                          | Открывает `http://anime-db.org/` в браузере |
| Exit                           | `QCoreApplication::quit()`                  |

## Настройки (`config.ini`)

Хранятся в INI-файле, управляются через [MSettings](TECHNICAL.md). Ключи:

| Ключ          | Дефолт              | Назначение                                                    |
|---------------|---------------------|---------------------------------------------------------------|
| `addr`        | `0.0.0.0`           | Адрес привязки веб-сервера PHP ⚠️ (см. [BUGS.md#b1](BUGS.md)) |
| `port`        | `56780`             | Порт веб-сервера                                              |
| `php`         | `./bin\php\php.exe` | Путь к интерпретатору PHP (относительный → от exe)            |
| `lastAppPath` | (текущий путь exe)  | Где приложение лежало в прошлый раз (для сброса кэша)         |

## Что НЕ входит в репозиторий

Каталоги `app/`, `web/`, `bin/php/` — это часть **дистрибутива Anime DB**, который раскладывается рядом с `anime_monitor.exe` при установке. В этом репозитории их нет; `monitor` лишь ссылается на них во время выполнения относительно своей папки.
