# Аудит проекта `anime-db/monitor`

Сводный отчёт по результатам полного разбора репозитория. Детали — в связанных документах: [PROJECT.md](PROJECT.md), [TECHNICAL.md](TECHNICAL.md), [BUGS.md](BUGS.md), [RECOMMENDATIONS.md](RECOMMENDATIONS.md).

## Что это

`monitor` — крошечная (≈330 строк C++) десктопная утилита-лаунчер для **Windows**, живущая в системном трее. Её единственная задача — поднять локальную инсталляцию веб-приложения **Anime DB** (Symfony/PHP) через встроенный веб-сервер PHP и открыть её в браузере. Это **супервизор-обёртка**, а не само приложение. Подробнее — [PROJECT.md](PROJECT.md).

## Вердикт

Код **рабочий, но сырой и небезопасный по умолчанию**. Это типичная утилита «выходного дня» 2014 года: решает задачу в happy-path, но имеет дефолт, открывающий приложение всей локальной сети, не выполняет роль «монитора» (не следит за упавшими процессами), и содержит несколько багов из-за неверных предположений об API Qt и путях.

## Топ находок

### 🔴 Критично для безопасности
1. **Сервер слушает `0.0.0.0` по умолчанию** — встроенный веб-сервер PHP (не предназначенный для продакшна) доступен всей локальной сети, а не только `127.0.0.1`. См. [BUGS.md#b1](BUGS.md) и [RECOMMENDATIONS.md](RECOMMENDATIONS.md).

### 🟠 Функциональные баги
2. **Редирект `>nul 2>&1` не работает** — `QProcess::start(QString)` не запускает шелл, поэтому токены редиректа уходят в `php` как обычные аргументы. См. [BUGS.md#b2](BUGS.md).
3. **`config.ini` сохраняется относительно рабочего каталога (CWD), а не папки exe** — настройки могут «теряться» при запуске из ярлыка. См. [BUGS.md#b3](BUGS.md).
4. **Гонка при открытии браузера** — URL открывается сразу после `start()`, до того как PHP-сервер успел забиндиться. См. [BUGS.md#b5](BUGS.md).

### 🟡 Концептуальный пробел
5. **«Монитор» ничего не мониторит** — упавший дочерний процесс не детектируется и не перезапускается. Имя обещает больше, чем делает код. См. [BUGS.md#b6](BUGS.md).

### 🟡 i18n / лицензия / гигиена
6. **Русский перевод привязан к стране (`RussianFederation`), а не к языку** — русскоязычные за пределами РФ видят английский UI. См. [BUGS.md#b4](BUGS.md).
7. **Нет GPLv3-заголовков** в исходных файлах при заявленной лицензии. См. [RECOMMENDATIONS.md](RECOMMENDATIONS.md).
8. **Закоммичен `anime_monitor.pro.user`**, нет `.gitignore`.

## Рекомендуемые первоочередные шаги

1. Сменить дефолт `addr` на `127.0.0.1` (быстрый фикс безопасности).
2. Исправить запуск процессов: либо `cmd /c` для редиректа, либо `QProcess` с `setStandardOutputFile(QProcess::nullDevice())` и `start(program, args)`.
3. Резолвить `config.ini` от `applicationDirPath()`.
4. Открывать браузер после готовности сервера (опрос порта / сигнал `started()` + задержка).
5. Добавить GPLv3-заголовки и `.gitignore`.

Полный список — [RECOMMENDATIONS.md](RECOMMENDATIONS.md).
