# Глоссарий `anime-db/monitor`

Термины и имена, которые легко трактовать неверно: опечатки-как-символы, исторический нейминг, сущности с неочевидными именами.

## Имена в коде

| Имя                 | Что это на самом деле                                                                                          |
|---------------------|----------------------------------------------------------------------------------------------------------------|
| `lunchProcesses()`  | Опечатка от *launch*. Запускает оба процесса PHP. Реальный символ — не «обед».                                 |
| `clearCash()`       | Опечатка от *cache*. Чистит кэш Symfony (`cache:clear`). Не про деньги.                                        |
| `MSettings`         | Синглтон-обёртка над `QSettings` (`config.ini`). Префикс `M` — авторский («My»?).                              |
| `MLogger`           | Вырезанный логгер: остались только закомментированные `//#include`/`MLogger::info`. В проекте логирования нет. |
| `routerProc`        | `QProcess` встроенного веб-сервера PHP (`php -S ... router.php`). «router» = front-controller.                 |
| `taskSchedulerProc` | `QProcess` планировщика Symfony (`php -f app/console animedb:task-scheduler`).                                 |
| `appDirPath`        | Папка, где лежит `anime_monitor.exe` (`applicationDirPath()`).                                                 |
| `lastAppPath`       | Сохранённый в `config.ini` `appDirPath` прошлого запуска. Сравнение → сброс кэша.                              |
| `leftMenu`          | Меню Start/Stop/Restart, всплывающее по ЛЕВОМУ клику. (Контекстное по правому — отдельное.)                    |
| `reason == 3`       | `QSystemTrayIcon::Trigger` — левый клик по иконке. Магическое число.                                           |
| `isPathChanged()`   | Объявлен в `TrayIcon.h`, нигде не определён/не вызван. Мёртвый код, не функция-загадка.                        |

## Сущности и артефакты

| Имя                      | Что это                                                                                                                                                                                         |
|--------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **monitor**              | Несмотря на имя — это **лаунчер/супервизор**, а не мониторинг. Запускает и забывает; за упавшими процессами не следит (см. [gotchas.md](gotchas.md), [../docs/BUGS.md#b6](../docs/BUGS.md#b6)). |
| **Anime DB**             | Само приложение — веб-каталог аниме на **Symfony/PHP**. Живёт в других репозиториях `anime-db/*`. monitor лишь поднимает его.                                                                   |
| `router.php`             | Скрипт-роутер встроенного сервера PHP (`php -S host:port router.php`), фронт-контроллер. Не «сетевой роутер».                                                                                   |
| `animedb:task-scheduler` | Команда Symfony-консоли (`app/console`), фоновый планировщик задач приложения.                                                                                                                  |
| `app/console`            | Symfony-консоль приложения Anime DB (вне этого репозитория, рядом с exe в дистрибутиве).                                                                                                        |
| `ru.ts`                  | **Исходник** перевода (Qt Linguist, XML). Редактируется человеком/`lupdate`.                                                                                                                    |
| `ru.qm`                  | **Скомпилированный** бинарь перевода (`lrelease`). Грузится в рантайме. Правка `.ts` без `lrelease` ни на что не влияет.                                                                        |
| `tray.png`               | Иконка В ТРЕЕ.                                                                                                                                                                                  |
| `favicon.ico`            | Иконка САМОГО exe (через `myapp.rc` + `RC_FILE`). Вшита и в `icons.qrc`, и в `.rc`.                                                                                                             |
| `anime_monitor.pro`      | Проект **qmake** — единственный список файлов сборки.                                                                                                                                           |
| `anime_monitor.pro.user` | Локальное состояние **Qt Creator** (пути конкретной машины). Не должно быть в VCS.                                                                                                              |
| `config.ini`             | Файл настроек (`addr`/`port`/`php`/`lastAppPath`). Путь резолвится от CWD — см. [gotchas.md](gotchas.md).                                                                                       |

## Дистрибутив vs репозиторий

| Термин                     | Уточнение                                                                                                                                       |
|----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `app/`, `web/`, `bin/php/` | Это части **дистрибутива Anime DB**, раскладываются рядом с exe при установке. В ЭТОМ репозитории их нет — monitor ссылается на них в рантайме. |
| «дистрибутив»              | Собранный комплект для пользователя: `anime_monitor.exe` + Anime DB + портативный PHP.                                                          |
