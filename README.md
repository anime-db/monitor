monitor
=======

The application monitor for Windows

---

## Что это такое

`monitor` — маленькая программа для **Windows**, которая живёт значком в системном трее (рядом с часами) и служит «кнопкой запуска» для приложения [Anime DB](https://anime-db.org/) — веб-каталога вашей коллекции аниме.

Само Anime DB написано на PHP (Symfony) и работает как сайт. Чтобы обычному пользователю не возиться с командной строкой, `monitor` берёт это на себя:

1. поднимает локальный веб-сервер PHP с приложением Anime DB;
2. запускает фоновый планировщик задач Anime DB;
3. открывает приложение в браузере (`http://localhost:56780/`).

Программа — это **обёртка-лаунчер**, а не само приложение. Логика каталога живёт в других репозиториях проекта [anime-db](https://github.com/anime-db).

## Как пользоваться

- **Запуск.** Откройте `anime_monitor.exe` — появится иконка в трее, через секунду откроется браузер.
- **Левый клик по иконке** — меню `Start` / `Stop` / `Restart` (запустить / остановить / перезапустить приложение).
- **Правый клик** — `About` (сайт проекта) и `Exit` (выход).
- Запущен может быть только **один** экземпляр программы одновременно.

## Требования и ограничения

- Только **Windows**.
- Рядом с `anime_monitor.exe` должны лежать файлы дистрибутива Anime DB (`app/`, `web/`, `bin/php/`).
- **Путь к программе — только латиница без пробелов** (например, `C:\AnimeDB\`). В путях с пробелами или кириллицей встроенный сервер PHP не работает, и программа об этом предупредит.
- Настройки (адрес, порт, путь к PHP) хранятся в файле `config.ini`.

## Для разработчиков

- Стек: **C++/Qt** (Qt4/Qt5), сборка через **qmake** (`anime_monitor.pro`), обычно открывается в **Qt Creator**.
- Полная документация, технический разбор и результаты аудита — в каталоге [`docs/`](docs/index.md).
